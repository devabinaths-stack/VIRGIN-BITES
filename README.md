# Virgin Bites website

A mobile-first Next.js website for Virgin Bites, using the café’s green and burgundy identity and “Unadulterated Love” branding.

## Features

- Burger loading animation and a photo-led opening page
- Café and bulk menus with category photos, searchable dish names, and no prices
- Event stall enquiry section
- Tap-to-call, WhatsApp, email, and Google Maps links for Virgin Bites
- Aegon Studioz branding and contact links at the end of the site
- Responsive navigation, touch-friendly controls, and reduced-motion support

## Run locally

```bash
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:3000`.

## Project files

- `app/page.tsx` contains the menus, business contact details, and page content.
- `app/globals.css` contains the site styling and responsive layout.
- `public/images/` contains the local logos and menu category photos.
